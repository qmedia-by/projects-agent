# Настройка

Один раз, минут двадцать. В конце вы спрашиваете о проекте обычным текстом по-русски.

Все названия кнопок здесь — как они выглядят на экране, по-английски. **Русский языковой пакет для VS Code не ставьте**: с ним кнопки называются иначе, и эта инструкция перестанет совпадать с тем, что вы видите.

Если у вас уже настроен инструмент для рекламы (`qmedia-ads-agent`), шаги 1–4 пройдены — начинайте с шага 5.

## Перед началом

Три вещи, без которых дальше идти бессмысленно:

- **Доступ к ChatGPT** — рабочая учётная запись.
- **Ваш адрес Google внесён в список менеджеров сервера.** Напишите администратору инструмента, каким Google-аккаунтом будете входить, и дождитесь ответа. Без этого шаг 8 не пройдёт: вход в браузере получится, а сервер вас не пустит.
- **Права администратора на компьютере — только для Windows.** Один раз понадобятся на шаге 9.

## 1. Установите VS Code

Скачайте с [code.visualstudio.com](https://code.visualstudio.com/) и установите.

## 2. Установите Git

Скачайте с [git-scm.com/downloads](https://git-scm.com/downloads) и установите, ничего не меняя: во всех окнах жмите **Next**, в последнем — **Install**.

Это программа, которая скачивает и обновляет инструмент. Открывать её никогда не придётся.

## 3. Установите расширение Codex

В VS Code слева — колонка значков. Нажмите **Extensions**, в поиске наберите `Codex`, у расширения **Codex - OpenAI's coding agent** нажмите **Install**.

## 4. Войдите в Codex

Справа появится значок Codex. Нажмите его (или `Ctrl + Alt + B`) — откроется чат. Нажмите **Sign in**, войдите в браузере рабочей учётной записью и вернитесь в VS Code.

## 5. Скачайте папку инструмента

В колонке значков нажмите **Source Control**, затем **Clone Repository**. В поле сверху вставьте адрес:

```
https://github.com/qmedia-by/projects-agent.git
```

Когда спросят, куда сохранить, выберите удобную папку, например **Documents**. Когда предложат открыть — **Open**.

Потеряете папку в VS Code — **File → Open Recent**.

## 6. Разрешите Codex работать с папкой

Codex спросит, доверяете ли вы этой папке. Ответьте **Trust**. Без этого он не увидит адрес сервера.

## 7. Включите автообновление

Откройте настройки Codex, раздел **Hooks**. Там будет строка с пометкой **New hook** — нажмите **Trust**.

> Если строки нет, начните новый чат, напишите «Привет» и загляните в **Hooks** снова.

Пропустите шаг — обновления просто не будут приходить, и вы об этом не узнаете.

## 8. Подключите сервер проектов

В чате Codex напишите:

```text
Подключи сервер проектов
```

Агент откроет вход в браузере. Ваше дело:

- выбрать **рабочий** аккаунт Google — тот, адрес которого вы назвали администратору;
- разрешить доступ на странице сервера, если она появится, и на странице Google;
- вернуться в VS Code.

Готово, когда агент скажет, что сервер подключён.

## 9. Проверьте

В чате Codex напишите:

```text
Проверь подключение
```

Агент назовёт, что работает, а что нет, и даст одно следующее действие. На Windows здесь же в первый раз запросят права администратора — согласитесь.

Затем задайте первый настоящий вопрос:

```text
Что горит у меня? Моя фамилия в листе «Проекты» — <фамилия>.
```

## Что вы увидите по дороге

| Экран | Что это | Что делать |
|---|---|---|
| Google: выбор аккаунта | вход на сервер проектов | выбрать рабочий аккаунт |
| Страница сервера с просьбой разрешить доступ | сервер спрашивает, пускать ли Codex | разрешить |
| Окно с командой и кнопкой подтверждения | агент просит разрешения выполнить команду или вызвать сервер | разрешить, и поставить галку «всегда», если она есть |
| Запрос прав администратора (только Windows) | Codex один раз настраивает себе песочницу | согласиться |

## Обновления

Инструмент обновляется сам при открытии нового чата. Когда это произошло, агент скажет об этом и попросит открыть **New chat**: правила читаются только в начале чата, поэтому обновление вступает в силу с нового.

Проверить вручную:

```text
Обнови инструмент
```
